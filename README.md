# jbconan.fr

Personal site of Jean-Baptiste Conan: a static home page and a Markdown blog, built with Vite.

```bash
npm install
npm run dev      # local dev server
npm run build    # writes the site to dist/
```

## Writing a post

Copy `posts/_template.md` to `posts/my-post-name.md`, then fill it in. The post appears at
`/blog/my-post-name/` and in the list at `/blog/`, newest first. Files starting with `_` are drafts.
